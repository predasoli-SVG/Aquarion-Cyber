# Modelo de produção

Coloque `pisces-electronica.glb` aqui e ative o caminho em `src/config.js`. A edição inicial usa 278 peças procedurais, sem download de modelo.

Eixo X longitudinal, cabeça +X, Y para cima. Cada peça destacável deve ser um mesh rígido. Aplique transformações e bake skins antes de exportar. Materiais glTF metallic-roughness, UVs válidos e nomes descritivos. Consulte ARCHITECTURE.md para o contrato completo.
